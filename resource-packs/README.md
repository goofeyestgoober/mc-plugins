# Resource packs

## shardsmp/
Textures for the ShardSMP plugin's 11 shards plus the Reroller (Minecraft 1.21.11).
Turn on `use-custom-textures: true` in the plugin's `config.yml` when players use this pack.

To install it: zip the *contents* of the `shardsmp/` folder (`pack.mcmeta` must be at the top level of the zip),
then put the zip in the client's `resourcepacks` folder or use it as the server's resource pack.
